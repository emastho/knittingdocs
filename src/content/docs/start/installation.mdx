Check the requirements below, then install Knitting with your runtime’s package manager.

## Requirements

- Node.js 22+
- Deno 2+
- Bun 1.0+

You can also try thread pools on Andromeda 0.1.14. Support is experimental, and
you'll need to bundle Knitting first. The [Andromeda guide](/guides/andromeda/)
walks through the setup.

## Install

Knitting is published on npm as `knitting`. Check your installed version and
lockfile before using release-specific options; the documentation baseline is
generated in [llms.txt](/llms.txt) from this site’s resolved dependency.

<Tabs>
  <TabItem label="npm"><Code code="npm install knitting" lang="bash" title={"npm.sh"} /></TabItem>
  <TabItem label="Deno"><Code code="deno add --npm knitting" lang="bash" title={"deno.sh"} mark={['--npm']} /></TabItem>
  <TabItem label="Bun"><Code code="bun add knitting" lang="bash" title={"bun.sh"} /></TabItem>
</Tabs>

:::note
Knitting is also published on JSR as `@vixeny/knitting` — the same code under a
scoped name. The npm package is the simplest path on every runtime, so prefer it
unless you specifically need the JSR entry.
:::

:::caution[Deno thread workers]
On Deno, thread pools need the npm package. Knitting starts thread workers
through `node:worker_threads`, which in Deno only accepts `file:` and `data:`
URLs. Imported from JSR, Knitting's modules have `https:` URLs, so
`createPool()` fails as soon as it starts a worker. Install it with
`deno add --npm knitting` and set `nodeModulesDir` to `"auto"` in your
project's root `deno.json`:

```json
{
  "nodeModulesDir": "auto"
}
```
:::
